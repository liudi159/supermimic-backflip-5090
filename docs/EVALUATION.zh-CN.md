# 评测定义与未解决问题

## 策略与物理求解

使用真正最终`last.pt`的策略与归一化状态，从静止初始状态出发，在IsaacLab / Newton / MuJoCo-Warp中逐步控制。50Hz控制，每步4次5ms物理子步。执行过程中没有标定夹具、姿态替换、失败重置或参考轨迹覆盖。参考只用于策略目标和误差计算。

固定额外保持5秒，目标保持动作末帧，停止参考速度；稳定性门槛检查该段最后2秒。不能将这项检查简写成“整个5秒所有时刻都无晃动”。

## strict_v3工程验收

这些是本实验用于发现姿态问题的**工程门槛，不是论文原始成功定义**。保持旧实验的物理门槛，但新实现原生骨盆奖励与旧躯干奖励不可数值等同。

| 检查 | 门槛 |
|---|---|
| 起始速度 | 根和关节速度为零 |
| 完整后翻 | 矢状面累计旋转在−370°到−350° |
| 腾空翻转 | 腾空累计旋转至少250°，左右轴最小对齐大于0.8 |
| 非脚部触地 | 整段运动和额外保持没有非脚部几何穿透 |
| 姿态 | 腾空髋膝RMSE小于25°；最大脚踝间距不超过同窗参考最大值+0.15m |
| 落地末2秒 | 水平漂移<0.1m；线速度RMS<0.1m/s且最大<0.2m/s；角速度RMS<0.2rad/s；竖直轴投影>0.99 |
| 奖励与基础门槛 | 本实现原生return至少0.75，并通过代码中的legacy gate |

具体计算以`scripts/evaluate_reference_backflip.py`为准。没有腾空段时不输出“0误差”造成误导，而使用null。旋转轴偏斜为`acos(最小左右轴对齐)`，不是角动量轴的另一种估计。

左右腿不对称：左右六关节按镜像符号`[1,-1,-1,1,1,-1]`匹配，再减去参考动作本身的左右差；报告RMSE。固定准备/起跳/腾空窗口分别为帧50:75、75:90、90:118，不随实际动作移位以挑选好看的片段。

## 200 Hz接触力

在真实GPU求解器每个物理子步之后，用`mujoco_warp.get_data_into`复制已求解状态与约束力，再用`mj_contactForce`读取和转到世界坐标；没有用CPU重新求解的力替代原始力。必须读取`contact.geom`，旧别名`geom1/geom2`在这一回传路径未被填充。

静态校验结果：机器人33.341kg，左右161.69/161.11N，总支撑约重量的98.69%，接触合力与根部约束力最大误差0.00283N。用带记录器试验与两次无记录器试验对照，记录引入的状态差小于正常重复波动。校验的水平/姿态夹具不施加竖直支撑；它与关节静力前馈仅存在于`probe_reference_env.py`。

最终策略受力：

| 窗口 | 左冲量 | 右冲量 | 不平衡比例 |
|---|---:|---:|---:|
| 固定准备1.0–1.5s | 73.22 N·s | 98.81 N·s | 14.88% |
| 固定起跳1.5–1.8s | 90.96 N·s | 81.71 N·s | 5.36% |
| 实际腾空前0.3s（1.44–1.74s） | 108.96 N·s | 96.49 N·s | 6.07% |

不平衡比例为`abs(L-R)/(abs(L)+abs(R))`。无受力时记null，不解释成完美对称。以竖直力5N、至少持续20ms为离地事件标准，两脚首个离地均为1.725s；50Hz几何标准也给出零离地差。左脚落地后在2.65/2.675s还有卸载事件，完整事件列表已保留，没有只选一个有利事件。

最终合力/约束力最大差0.00568N。两腿都曾达到记录的力矩限值比例1.0；这是饱和证据，不能仅凭此认定不对称根因。

## 最终失败项：几何穿透与接触力不是同一个量

最终9029检查点的帧119（2.38s）存在右小腿与踝部几何穿透约1.06–1.82mm；但200Hz实际求解器记录的非脚部受力样本数为0。详见`results/v14/nonfoot_contact_audit.json`。

几何检查是在保存的真实姿态上重建接触几何，用于严格质量评测；力来自原始GPU求解。碰撞表示、接触阶段或重建约定可能涉及差异，但目前没有单变量证据解释唯一原因。**不能把两者不一致解释成已修复，也不能删掉几何失败项。** 当前`success:false`原样保留。

后续可针对接触重建一致性、落地右腿余量和两侧饱和时刻做验证，再进行同初始化同seed单变量配对试验。本文仓库没有声称该后续优化已完成，也没有为获得通过而延长本轮训练。

## 发布前独立复评

同一最终9029权重，通过整理后的可移植评测入口独立运行：脚踝间距0.37585m、轴偏斜7.7384°、髋膝RMSE7.1946°，此次几何非脚部触地0帧，strict success为true。原始交付结果仍为1帧/false，两次都保存在results/v14。

这说明宏观姿态结果可重复，但毫米级落地接触对重复运行数值差异敏感。单次独立通过不覆盖首次失败，不宣称稳定通过所有重复试验；也未为复评修改任何门槛。
